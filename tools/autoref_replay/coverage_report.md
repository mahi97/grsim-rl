## Integration Notes

This report is based on *static* analysis of detector coverage. Full frame-by-frame log replay requires:

1. Python bindings for `EventDetectorRegistry` (pybind11)
2. An SSL log parser (protobuf `SSL_WrapperPacket` frames)
3. A WorldState adapter that converts vision frames to `grsim_core::WorldState`

Once those are in place, `_step_log_frames()` in this script can be filled in to provide true detection accuracy metrics.
